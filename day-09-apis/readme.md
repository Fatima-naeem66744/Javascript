# Day 09 — APIs

This project demonstrates working with a real public API using JavaScript's `fetch()` API, `async/await`, and REST concepts. The page fetches live user data from JSONPlaceholder using a GET request and displays the user's name, username, email, and city in a readable DOM layout. A visible loading state appears while the request is in progress, and errors are handled with a clear message without causing an unhandled promise rejection. The last successful user response is saved in `localStorage` and automatically displayed when the page is reloaded. The project also demonstrates a POST request to JSONPlaceholder's `/posts` endpoint, with the response logged in the console. The page is styled with a soft lavender design using `style.css`.
