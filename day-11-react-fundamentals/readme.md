# Day 11: React Fundamentals - Static Component Library

This project is a modular React application built with Vite that demonstrates core component architectures by constructing a reusable static UI library. It features independent, props-driven building blocks—including a dual-variant `Button`, a dynamically rendered `Navbar`, a media `Card`, and a `ProfileCard`—composed together on a single landing page with realistic sample data. Every component prioritizes strict content separation via props and key-based list rendering, styling all elements with modern CSS variables, responsive CSS grids, and smooth interaction states.
