## Day 12: Interactive Counter & Validated Form
This project demonstrates core React state management techniques by featuring an interactive counter whose state is lifted to a common parent component (App) and shared with a sibling display component, alongside a live-validated form where email and password inputs are fully controlled via useState to render instant, conditional feedback upon typing.
