# Day 16 — Project 2: Task Manager CRUD

Today I built out the Task Manager application with full CRUD functionality using React, Context API, `fetch()`, and a `json-server` mock backend. The app can create, read, update, and delete tasks, with all CRUD operations connected to the global `TaskContext` so changes are reflected throughout the application and persist after refreshing the page. I also added basic title validation, Tailwind CSS styling, and clear loading, empty, and error states to provide a cleaner user experience. The project now demonstrates how a React frontend communicates with a backend API while keeping shared task data in global state.
